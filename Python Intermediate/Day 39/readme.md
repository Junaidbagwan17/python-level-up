
# ✈️ Cheap Flight Finder Bot

A Python automation project that checks flight prices from a Google Sheet and sends Telegram alerts when a cheaper flight is found.

This project was built using:
- Python
- OOP (Object-Oriented Programming)
- Sheety API
- Telegram Bot API
- Requests library
- Datetime module

---

# 🚀 Features

✅ Fetch destination data from Google Sheets using Sheety API  
✅ Generate mock flight data  
✅ Compare current flight prices with lowest prices  
✅ Send Telegram notifications for cheap flights  
✅ Multi-file modular project architecture  
✅ OOP-based design using custom classes
